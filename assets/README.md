# ServalApp – Assets

Ce dossier contient les ressources visuelles et techniques du projet ServalApp.

## Structure
- `stylesheets/` : fichiers CSS (style principal)
- `javascripts/` : scripts JS (scripts.js)
- `icons/` : icônes et logo ServalApp

## Objectif
Centraliser les fichiers statiques utilisés par le prototype ServalApp.
