# 🐾 ServalApp
- Icon Pack

Ce fichier regroupe toutes les icônes officielles de ServalApp dans un seul ensemble cohérent, prêt à être intégré dans ton projet web ou mobile.

---

### 📂 Structure du pack
```text
assets/icons/
│── favicon.ico
│── apple-touch-icon-57.png
│── apple-touch-icon-72.png
│── apple-touch-icon-114.png
│── apple-touch-icon-144.png
└── ms-TileImage.png
```

- Chaque fichier correspond à une taille et un usage spécifique :

| Fichier | Taille | Usage principal |
|----------|---------|----------------|
| favicon.ico | 16×16 | Icône du navigateur |
| apple-touch-icon-57.png | 57×57 | iPhone (ancienne génération) |
| apple-touch-icon-72.png | 72×72 | iPad (ancienne génération) |
| apple-touch-icon-114.png | 114×114 | iPhone Retina |
| apple-touch-icon-144.png | 144×144 | iPad Retina |
| ms-TileImage.png | 310×150 | Windows / Microsoft Tile |

---

### ⚙️ Intégration dans ton projet
- Ajoute ces lignes dans ton fichier HTML principal (index.html) :
```html
<link rel="icon" type="image/x-icon" href="assets/icons/favicon.ico">
<link rel="apple-touch-icon" sizes="57x57" href="assets/icons/apple-touch-icon-57.png">
<link rel="apple-touch-icon" sizes="72x72" href="assets/icons/apple-touch-icon-72.png">
<link rel="apple-touch-icon" sizes="114x114" href="assets/icons/apple-touch-icon-114.png">
<link rel="apple-touch-icon" sizes="144x144" href="assets/icons/apple-touch-icon-144.png">
<meta name="msapplication-TileImage" content="assets/icons/ms-TileImage.png">
<meta name="msapplication-TileColor" content="#000000">
```

### 🎨 Design et identité
- Les icônes reprennent le logo ServalApp :
- Tête de serval stylisée sur fond de bouclier tactique orange et noir.
- Compatible avec iOS, Android, Windows et Web.
- Fond transparent pour une intégration fluide dans tous les thèmes.

---

### 🧩 Utilisation recommandée
- Place le dossier assets/icons/ à la racine de ton projet.
- Vérifie que les chemins dans le HTML correspondent à ta structure.
- Pour Android, tu peux aussi générer des Adaptive Icons à partir de ces fichiers.
